# liftgraph

Lift encode/decode helpers for graph payloads in pipelines.

**Site:** https://theworker02.github.io/liftgraph/

## Install / run

```bash
git clone https://github.com/theworker02/liftgraph.git
cd liftgraph
node src/cli.js
node --test
```
